# IMAGO Representation Model

## Definition
A Representation is a computable, explainable, traceable and revisable description of a subject, system or phenomenon built from incomplete observations.

It is not reality. It is the best available model within a declared context and time.

## Conceptual pipeline
```text
Reality
→ Observation
→ Evidence
→ Measurement
→ Knowledge
→ Representation
→ Application
→ Decision or Action
```

## Minimum properties
A Representation may declare:
- represented subject or phenomenon;
- current state;
- source material;
- evidence and derived knowledge;
- context and temporal validity;
- provenance and dependencies;
- uncertainty;
- version;
- history and transitions;
- permissions where personal data is involved.

## Application independence
Applications consume the Representation to produce reports, simulations, dashboards, plans or documents.

## Professional Identity
In the professional domain, the persistent Representation is the Professional Identity.
