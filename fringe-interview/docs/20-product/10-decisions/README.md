# Product Decisions

## Purpose

This directory contains the canonical product decisions that define IMAGO.

A Product Decision is:

- implementation-independent;
- stable;
- authoritative;
- intentionally concise.

Product Decisions define **what the product must do**, never **how it is implemented**.

Architecture and implementation must conform to these decisions.

## Record format

Each decision contains only:

- Identifier
- Title
- Status
- Decision

Long explanations belong elsewhere.

## Status

- CANONICAL
- DEPRECATED
- SUPERSEDED

Only CANONICAL decisions define the current behaviour.

## Editorial rules

- One record = one decision.
- One concept = one sentence.
- Records must remain compact.
- Avoid repetition.
- Documents must be easy to browse and search.
