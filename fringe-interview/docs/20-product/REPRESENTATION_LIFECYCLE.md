# IMAGO Representation Lifecycle

## Lifecycle
```text
Create
→ Acquire inputs
→ Extract and validate knowledge
→ Build current Representation
→ Use in applications
→ Add new evidence or experience
→ Create a new dated snapshot
→ Continue
```

There is no natural functional end to a professional Representation.

## Snapshot rule
Relevant updates create a new reconstructible snapshot. Current and prior states remain distinguishable.

## Account and retention states
A product account may move through:
- active;
- frozen after subscription expiry;
- technical retention period;
- deletion of identifiable personal data;
- possible retention of legally valid anonymized or aggregated data.

Exact periods and lawful basis require privacy and legal review.

## Anonymization rule
Removing a name alone is not sufficient anonymization.

## Future dynamic domains
The model must not prevent future support for event streams, rapidly changing states, transitions, anomaly detection or evolving models.
