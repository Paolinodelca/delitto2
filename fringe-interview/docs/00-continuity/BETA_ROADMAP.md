# Private Beta Roadmap

Status: CURRENT

Target:

Private Beta — IMAGO Interview

---

# Objective

Deliver the smallest coherent implementation that provides real value to beta testers while preserving the long-term architecture of the IMAGO platform.

The roadmap is product-driven.

Architectural hardening activities are implemented only when consumed by the active Beta path or when they represent concrete blockers.

---

# Milestone 1 — Beta User Journey

## Objective

Complete the entire Beta user journey without blocking issues.

## Done when

A new beta tester can:

- start a session;
- complete the interview;
- receive the final report;
- finish the experience without blocking errors.

## Completed Tasks

### M1-01 — Beta User Journey Completion Gate

Status: COMPLETED — 2026-08-05

The application session output now exposes a deterministic `betaUserJourney` assessment covering session start, interview completion, final report construction and session closure. Partial sessions no longer report `meta.completed: true`; explicit blockers make incomplete journeys observable without extending the Core.

### M1-02 — Private Beta User Journey Verification

Status: COMPLETED — 2026-08-05

The Application now exposes a minimal reusable verification wrapper that runs the Beta session runner and accepts the journey only when the M1-01 completion gate, Interview Runtime completion, final report availability and Beta Session closure all agree. Dedicated deterministic tests cover both the successful path and explicit incomplete-output failures without extending the Core.

## Candidate Tasks

- end-to-end verification;
- onboarding;
- privacy & consent;
- error handling;
- minimum feedback collection;
- operational logging.

## Out of Scope

- Professional Identity evolution;
- Core hardening (E-44);
- Coverage / Matrix integration;
- multi-provider support.

# Milestone 2 — Perceived Value

## Objective

Increase the quality and usefulness of the report generated by IMAGO Interview.

## Done when

Beta testers perceive the report as coherent, useful and actionable.

## Candidate Tasks

- Professional Perception calibration;
- improve report summary;
- explicit evidence → conclusion linkage;
- final recommended actions;
- insufficient-data handling;
- Professional Identity MVP.

## Out of Scope

- complete Career platform;
- future domains;
- advanced analytics.

---

# Milestone 3 — Beta Consolidation

## Objective

Freeze the Beta scope and prepare repeatable testing.

## Done when

The Beta is stable, documented and limited to a clearly defined functional perimeter.

## Candidate Tasks

- define CV Review scope;
- define supported Role Families;
- final Beta validation;
- Beta packaging.

## Out of Scope

- post-Beta architectural evolution;
- future platform domains.
