# Welcome

Questa cartella contiene la documentazione ufficiale del Builder.

L'obiettivo non è sostituire il repository.

Il repository rimane sempre la fonte primaria della verità.

La documentazione descrive:

* architettura;
* workflow;
* decisioni;
* stato;
* storia tecnica.

## Beta Philosophy

L'obiettivo corrente è raggiungere una Beta stabile.

Ogni nuova attività deve essere valutata in funzione del suo contributo al percorso verso la Beta.

Le ottimizzazioni non essenziali vengono pianificate per il post-Beta.
